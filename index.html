Wayland 95 updates

The apt repository for the wayland95 package (latest: 0.10.0). Wayland 95 installs it by itself. To add it to another Debian 13 system:

sudo curl -fsSLo /usr/share/keyrings/wayland95-archive-keyring.gpg https://pacificnm.github.io/wayland95/wayland95-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/wayland95.sources https://pacificnm.github.io/wayland95/wayland95.sources
sudo apt update && sudo apt install wayland95
